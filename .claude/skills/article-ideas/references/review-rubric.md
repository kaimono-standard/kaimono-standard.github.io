# レビューの採点基準

5つの視点で、候補ごとに 1〜5 点を付ける。各レビュアーは**自分の視点だけ**で採点し、他の視点の良し悪しで点を動かさない。点数には必ず理由を1〜2行付ける。

## 共通の点の付け方

| 点 | 意味 |
|---|---|
| 5 | この視点では文句なし。根拠がはっきりある |
| 4 | 良い。小さな懸念はあるが対処できる |
| 3 | 普通。書けるが、この視点での強みはない |
| 2 | 弱い。直さないと出す価値が薄い |
| 1 | この視点では成り立たない |

`kill` は「この問題が残るなら記事にしてはいけない」ものだけに付ける（点数が低いだけでは付けない）。

## demand（需要と時期）

- 5：検索や売れ行きの伸びを示す根拠が2つ以上あり、4〜8週間後に需要が続く見込み
- 3：定番の需要はあるが、いま伸びている根拠はない
- 1：根拠が話題1件だけ、または需要のピークが公開前に終わる
- kill：根拠URLがない

## monetization（収益とリンク）

- 5：楽天にメーカー公式店か大手の取り扱いがあり、候補5製品（新旧なら2製品）がそろう。Amazon にも国内正規品がある
- 3：楽天で揃うが、一般の販売店が中心
- 1：楽天で転売・並行輸入・中古ばかり、または価格がクーポン前提の表示（定価＋大幅値引きクーポン）で比べられない
- kill：楽天で新品を扱う店がほぼない

## verifiability（裏取りと規制）

- 5：メーカー公式ページに、比べる項目の数値が**文字で**載っている（画像だけではない）
- 3：一部の項目は画像やパッケージ表示でしか確認できない
- 1：主な比較項目が公式に載っていない
- kill：記事の中心が効能・効果の主張になる（薬機法・健康増進法・景品表示法）、または安全規格（PSE など）の確認が取れない電気製品が中心

## editorial（独自性と執筆者）

- 5：競合の記事が「おすすめ10選」型ばかりで、このサイトの型（公式仕様の比較表・新旧の違い・1gあたり等の換算）で差が出せる。執筆者の視点が活きる
- 3：書けるが、競合と同じ内容になりやすい
- 1：既存記事とほぼ重複する、またはこのサイトの型に合わない（体験談がないと価値がないジャンルなど）
- kill：既存記事と同じ内容

## contrarian（反対意見役・Codex）

- 各案の**一番弱いところ**を見つけ、「やめるべき理由」を必ず1つ書く
- 点数は「その弱点を直せるか」で付ける（5：簡単に直せる、1：直せない）
- 他の4視点が見落としそうな点（季節外れ、一過性の話題、読者の検索意図とのずれ、似た記事がすでに上位を固めている等）を優先する

```json
  ]

```

## candidates.json の形

```json
{
  "date": "2026-09-23",
  "candidates": [
    {
      "id": "c07",
      "title_draft": "○○5製品を比較。△△・□□で選ぶ",
      "genre": "季節家電",
      "article_type": "comparison",
      "editor_guess": "nao",
      "target_queries": ["○○ おすすめ", "○○ 比較"],
      "why_now": "なぜ今書くか（事実だけで1行）",
      "product_examples": ["ブランドA 型番", "ブランドB 型番"],
      "evidence": [{ "url": "...", "seen": "2026-09-23", "signal": "..." }],
      "risks": ["価格がクーポン前提の店が多い"],
      "revision": null
    }
  ]
}
```

`product_examples` は仮の例。記事を作るときに、公式仕様と楽天の取り扱いを確かめて選び直す。

## 最終案の書き方（ideas.md）

最終案ごとに、次の形で書く。

```markdown
### 1. ○○5製品を比較。△△・□□で選ぶ
- 型：5製品比較 ／ 担当：なお ／ ジャンル：季節家電
- 狙う検索語：「○○ おすすめ」「○○ 比較」
- なぜ今：（事実で1〜2行。根拠の要約）
- 根拠：[楽天デイリーランキング](URL)（9/23）、[PR TIMES](URL)（9/20）
- 候補製品の例：A、B、C、D、E（仮。記事作成時に選び直す）
- 実現性：公式仕様は文字で取れる／楽天に公式店3・大手2／Amazon 国内正規品あり
- 注意：（kill ではないが気をつけること）
- 評価：需要4・収益5・裏取り4・独自性4・反対意見4（合計21）
- 反対意見と答え：「季節の山が短い」→ 公開を2週間前倒しにする
```

最後に、見送った案のうち惜しかったものを3件まで、見送った理由つきで並べる（次回の候補になる）。
