# 調査の情報源

どの情報源も「需要がありそうだ」という**兆し**を拾うためのもの。記事の数値の出典にはしない（出典は記事作成のときにメーカー公式で取り直す）。候補には、兆しを見たページの URL と、見た日を必ず残す。

## 1. いま売れている・伸びている

| 情報源 | URL の例 | 何を見るか | 注意 |
|---|---|---|---|
| 楽天市場ランキング | `https://ranking.rakuten.co.jp/`（ジャンル別・デイリー・リアルタイム） | ジャンルごとの上位、急上昇。**同じ商品が複数の店で上位にいる**ものは需要が強い | ランキングは店単位。セール中は値引きで順位が動くので、セール期間かどうかも書く |
| 楽天市場の検索候補 | 楽天市場の検索窓の入力候補 | 「○○ おすすめ」「○○ 違い」などの組み合わせ | Chrome で人が入力するのと同じ範囲で見る |
| Googleトレンド | `https://trends.google.co.jp/` | 過去90日・12か月の伸び、季節の山、関連キーワード | 数値は相対値。「伸びている」「毎年この時期に山がある」の判断に使う |
| Yahoo!リアルタイム検索 | `https://search.yahoo.co.jp/realtime` | SNSで話題になり始めたもの | 一時的な話題が多い。1週間後も続いているかを確かめる |
| 価格.com の注目ランキング | `https://kakaku.com/` のカテゴリ別ランキング | 家電・PC周辺の関心の強さ | 手がかりとしてだけ使う。数値は記事の出典にしない |

**Amazon のランキングや価格はボットで抜き出さない**（アソシエイトの規約で禁止）。Amazon で見てよいのは、人が1回ずつ開くのと同じ範囲で「国内正規品が扱われているか」を確かめることだけ。

## 2. これから来る（新製品・新しい習慣）

| 情報源 | URL の例 | 何を見るか |
|---|---|---|
| PR TIMES | `https://prtimes.jp/`（カテゴリ・キーワード検索） | 直近60日の新製品、発売予定、新しいカテゴリの商品 |
| メーカーのニュースルーム | 各社の「ニュースリリース」「新製品情報」 | 新型の発売と、旧型との関係（「従来品○○比」「後継」）→ 新旧比較の候補 |
| ニュースサイトの家電・生活欄 | 家電Watch、ITmedia、Impress など | 新しいジャンルの立ち上がり（例：新しい形の家電が各社から出始めた） |

新旧比較の候補を見つけたら、旧型が楽天の公式店か大手で**新品として在庫があるか**も、この段階で軽く確かめる（在庫がなければ候補にしない）。

## 3. 季節・イベント

`assets/season-calendar.json` を起点にする。日付は例年のもので、**毎回公式の発表で確かめる**（楽天スーパーセールやプライムデーの日程は毎回変わる）。

- 記事は公開から検索に乗るまで2〜6週間かかることがある。**4〜8週間先**の需要を狙う
- セール前は「セールで買う前に比べておく」読者が増える。比較記事の需要が上がる時期として扱う（セール価格は書かない）
- 気温・天候で動くもの（暖房・加湿・冷感・梅雨・花粉）は、その年の予報やニュースも見る

## 4. 自サイトの検索データと隙間

- `_reports/analytics-*.md` の Search Console の検索語で、**表示回数はあるのにクリックが少ない、または合う記事がない**もの
- よく読まれている記事の読者が次に買いそうなもの（例：ケトルを読んだ人 → マグ・コーヒー器具）
- 既存の5機種比較の製品で、発売から時間がたって新型が出たもの（新旧比較）
- 既存記事の担当執筆者の偏り（`context.md` の執筆者別本数）。記事の少ない執筆者の視点に合う案を意識して探す

## 根拠として残す形

候補ごとに次を記録する。

```json
{
  "evidence": [
    { "url": "https://ranking.rakuten.co.jp/daily/...", "seen": "2026-09-23", "signal": "キッチン家電デイリーで同型の3店舗が20位以内" },
    { "url": "https://prtimes.jp/main/html/rd/p/....html", "seen": "2026-09-23", "signal": "2026年10月に各社から新型が出る" }
  ]
}
```

`signal` は「何を見て、なぜ需要があると判断したか」を事実だけで1行にする。「人気」「話題」だけの書き方はしない。
